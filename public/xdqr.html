Cómo funciona la llamada a tu API

Este panel hace exactamente esto por debajo: convierte tu logo en base64 y hace un POST a tu función qrApi con este cuerpo JSON: 

POST https://TU-ENDPOINT/qrApi
Content-Type: application/json

{
  "url": "https://tunegocio.com",
  "style": "style-neon",
  "dotShape": "rounded",
  "topText": "Mi Negocio",
  "subText": "Escanea y pide aquí",
  "captionText": "",
  "logo": "data:image/png;base64,iVBORw0KG...",
  "autoColor": true,
  "onlyQr": false
}

La respuesta es directamente el binario image/png de la tarjeta (o del QR suelto si onlyQr: true). Este panel lo recibe como blob, lo convierte en una URL local con URL.createObjectURL y lo muestra en el recuadro de la derecha.

Sobre las esquinas redondeadas del logo: eso lo dibuja tu plantilla generator.html (el archivo que carga Puppeteer), que no tengo en este momento — solo tengo qrGenerator.js. Si me lo compartes, le agrego border-radius y overflow: hidden al contenedor del logo para que quede tipo squircle premium, igual que la vista previa que ya ves arriba a la izquierda. Como referencia, esta es la idea: 

.logo-container {
  border-radius: 22%;   /* squircle, no cuadrado */
  overflow: hidden;
}
.logo-container img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
